# 任务3：债务企业自身监管

任务总结

1. **企业基本信息与资质：公司注册于2015年，注册资本1200万元，具备合法经营资质**  
   - 根据百度百科及官方渠道信息，四川振海保安服务有限公司成立于2015年12月10日，位于成都市武侯区，为有限责任公司（自然人投资或控股），法定代表人为马振朋，注册资本1200万元。公司经四川省公安厅批准设立，主营业务包括保安服务、工程建设活动、信息系统集成及安防设备销售，是四川省保安协会会员单位。  
   - **价值**：确认企业合法存续，具备一定抗风险能力（官网自称“拥有实体化办公场地”），但实缴资本及股东信息未在公开资料中披露，需进一步核实股权结构与资本到位情况，以评估实际偿债能力。

2. **诉讼风险：已出现劳动争议诉讼，涉及违法解除劳动关系赔偿、未签合同双倍工资等诉求**  
   - 爱企查披露的劳动争议法律文书显示，原告L某某向法院起诉，请求三被告连带支付违法解除劳动关系赔偿金57,400元、未签订劳动合同二倍工资差额45,100元及无法报销的医疗费7,000元。虽未明确列出被告全称，但结合案由与公司业务性质，四川振海保安服务有限公司极有可能是被告之一（同类劳动争议常见于保安服务企业）。  
   - **价值**：劳动争议是劳动密集型保安服务企业的高频风险点。此类诉讼可能暴露公司在用工合规性（合同签订、社保缴纳、解除程序）上的漏洞，若败诉将直接导致赔付支出，并可能引发更多同类纠纷，增加企业经营成本与声誉受损风险。

3. **招投标表现：有中标成功案例，但也因投标文件合规问题被废标，体现项目管理风险**  
   - 正面：2024年12月，公司以168.36万元中标仁寿县中医医院安保服务项目，评分为99.00分，显示出较强的竞标实力。  
   - 负面：2025年6月，在“高级职中物业管理服务采购（四次）”项目中，因“二次澄清不符合采购文件其他要求”被作无效处理，导致废标。  
   - **价值**：中标记录反映公司具备承接政府、医院等大型安保项目的能力，现金流可能较为健康；但废标事件暴露其投标响应质量不稳定，可能存在内部流程控制薄弱或人员专业度不足的问题。若多次废标，将影响后续中标率及收入稳定性，间接加剧财务风险。

4. **经营异常与合规隐患：未在直接搜索中发现严重异常记录，但行业监管趋严，存在间接关联风险**  
   - 截至当前检索结果，公司未被列入严重失信或经营异常名录（如官方网站运行正常、持续参与招投标）。但需要注意的是，本地政府（犍为县、甘孜州）2026年初发布了多批次吊销营业执照公告，针对连续两年未年报且无法取得联系的企业。虽然四川振海不在其中，但表明当地市场监管机构正加大清理力度。  
   - **价值**：公司目前看似合规，但若存在未披露的行政处罚、年度报告遗漏或地址变更未备案等细微问题，容易触发现行“连续2年未年报+失联”的吊销红线。需重点核查近三年年度报告公示情况及税务申报状态，防范潜在的吊销风险。

5. **财务风险线索：实缴资本不透明、无公开财务数据，薪酬纠纷可能引发连锁反应**  
   - 公开信息未提供企业的实缴资本、纳税情况、利润表等财务指标。仅注册资本1200万元，但实缴情况未知（对比同行山东振海实缴300万元/注册资本6002万元）。劳动争议中索赔金额虽不高（合计约10.95万元），但若公司未足额缴纳社保或存在系统性用工违规，可能面临劳动监察处罚及补缴义务，推高运营成本。  
   - **价值**：保安行业人员流动性大、社保负担重，若公司未为员工足额缴纳医疗保险（如原告所诉），则存在合规性风险。缺乏财务透明度意味着无法评估其资产负债率与现金流，建议调取企业信用报告或纳税评级作更深层风险研判。
