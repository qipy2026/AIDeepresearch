# 任务3：债务企业自身监管

任务总结

1. **工商注册与基本状态**  
   - 四川振海保安服务有限公司成立于2015年12月10日，注册资本1200万元人民币，注册地址位于成都市武侯区人民南路三段6号，法定代表人为马振朋，性质为有限责任公司（自然人投资或控股）。公司经四川省公安厅批准设立，主营保安服务、物业管理、安防设备销售等，并设有重庆分公司。  
   - **价值**：确认企业主体合法存续，但未在公开材料中披露实缴资本、股东背景及分支机构经营状况，需进一步核查其资金到位情况与关联方风险。

2. **公共采购参与及合规性问题**  
   - **正面案例**：2024年12月中标仁寿县中医医院安保服务（金额168.36万元），显示其具备一定业务承接能力。  
   - **负面案例**：2025年6月参与高级职中物业管理服务采购中，因“二次澄清不符合其他要求”导致项目终止，反映其在响应程序或服务标准执行上存在瑕疵。  
   - **价值**：采购活动中的合规失误可能预示内部管理薄弱，未来有被列入招投标失信名单的风险，间接影响企业现金流。

3. **劳动争议诉讼与用工管理缺陷**  
   - 通过爱企查法律文书发现，公司卷入一起劳动争议案件（原告L某某），诉请包括：违法解除劳动关系赔偿金57,400元、未签订劳动合同双倍工资差额45,100元、因未购买医疗保险导致的医疗费7,000元。  
   - **价值**：该案直接暴露公司存在未依法签订劳动合同、违法解聘、社保缴纳不完整等劳动法违规行为。即使单个案件金额不大，但如普遍存在，将累积大量赔偿义务和行政罚款，短期影响利润，长期可能引发员工集体维权或监管处罚。

4. **经营异常风险尚未显现，但隐患暗藏**  
   - 当前检索的所有官方公告（如犍为县、甘孜州吊销公告）均未直接指向四川振海，表明其暂未被列入经营异常名录或吊销营业执照。  
   - **价值**：表面信用良好，但结合劳动争议及采购违规，企业实际合规水平低于公示形象。需持续监控其年度报告报送情况、住所联系有效性，预防因持续未年报或地址失联被列入经营异常。

5. **财务风险迹象：低成本运营叠加法律代价**  
   - 公司官网强调“实体化办公、透明收费”，但劳动争议中未购买医保、未签合同的行为暗示其可能为控制成本而压缩法定福利支出。  
   - 注册资本1200万元，实缴情况不明；若实缴不足，则偿债能力有限。劳动争议赔偿金虽小（累计约10万元），但若多起诉讼同期爆发，可能迅速消耗少量流动资金。  
   - **价值**：建议通过企业信用报告核查实缴资本、纳税等级及社保缴纳人数，从侧面验证其财务健康度。当前证据显示其财务风险主要源于劳动合规成本，而非大规模债务违约。

**综合结论**：四川振海保安服务有限公司在工商层面正常存续，但通过政府采购违规和劳动争议诉讼暴露出内部监管薄弱：用工管理不规范、投标执行不严谨。这些“软风险”如不纠正，可能转化为经营异常、行政处罚甚至市场禁入。建议持续跟踪其年度报告、诉讼新增及招投标信用记录，以完善债务企业自身监管评估。
