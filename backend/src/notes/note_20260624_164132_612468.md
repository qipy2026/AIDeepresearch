# 任务2：核心企业监管（供应链扫描）

任务总结

1. **高频诉讼风险显著**：成都瑜璟物业服务有限公司（及双桥、武侯等分公司）存在大量物业服务合同纠纷诉讼，涉及追讨业主欠缴物业费、违约金及公摊水电费等。裁判文书显示，公司主动起诉频率高，说明其现金流管理依赖法律催收，且与业主关系紧张，可能隐含客户满意度下降或服务质量纠纷风险。

2. **部分分公司已注销**：企查查信息显示，成都瑜璟物业服务有限公司武侯分公司已处于“注销”状态（更新时间2025-12-10），说明该公司在区域布局上出现收缩或历史经营不善。供应链扫描中，需警惕关联主体异动对核心企业整体商誉和履约能力的负面影响。

3. **行业监管与舆论压力并存**：成都市纪委监委、新疆住建厅等官方渠道发布的典型案例显示，物业管理乱象（服务不透明、资金挪用、拒不交接等）正被专项整治。虽未直接点名瑜璟公司，但诉讼密集的特点使其容易成为监管关注对象。应持续监控其是否被列入失信名单或行政处罚。

4. **信用评价与招投标表现**：在四川招标网信息中，瑜璟公司叙永分公司被纳入“泸州市2023年度物业服务企业信用评价结果通报”，说明其参与当地招投标并接受信用管理，但目前未获取到具体评价等级。需进一步核实信用分是否影响后续项目获取。

5. **查询词“新街里南城都汇”无直接匹配结果**：当前检索的诉讼、行政处罚、舆情信息中，均未出现“新街里南城都汇”相关经营或风险记录。建议补充查询该物业项目对应的建设单位、业主委员会诉讼或物业服务满意度记录，以完成对甲方核心企业在该项目的风险闭环。
