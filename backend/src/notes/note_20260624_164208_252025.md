# 任务4：现场视频巡检

任务总结

根据现有检索资料，未直接获取到成都瑜璟物业服务有限公司“现场视频巡检”的具体巡检数据（如监控点位分布、巡检记录、系统截图等）。但通过对公司工商信息、资质、司法动态、分支机构等多维度信息梳理，提炼出以下与现场视频巡检能力及背景相关的关键发现，可为后续调研或直接联系企业提供参考。

1. **公司具备物业管理主体资质，理论上拥有视频巡检业务基础**  
   - 成都瑜璟物业服务有限公司成立于2009年，注册资本1000万元，拥有二级物业服务资质，主营业务包括物业管理、保洁服务等。  
   - 现场视频巡检通常是物业管理中秩序维护、安防监控的标准环节，公司的主体资质和技术团队（现有参保人员19人）可作为其具备巡检能力的间接证据。

2. **多分支机构覆盖，视频巡检可能涉及跨区域场景**  
   - 已知设有武侯分公司（负责人王茹琰，电话13881875033）、叙永分公司等，说明公司服务范围不止一个行政区域。  
   - 不同项目的监控系统可能存在异构，巡检数据需从各项目独立采集或通过统一平台归集，这一分散布局增加了巡检数据调研的复杂性。

3. **官网及企业邮箱公开，可视为获取巡检数据的潜在入口**  
   - 官方网址：www.cdyjwy.cn（从企查查/天眼查获取），官方邮箱：106831345@qq.com（武侯分公司）及497928639@qq.com（总公司）。  
   - 若需调取现场视频巡检记录，可尝试通过上述渠道联系公司信息技术部门或项目经理，索要巡检台账或监控系统接口说明。

4. **司法案件数量异常提示需关注监控合规风险**  
   - 天眼查显示总公司涉及“司法案件 4万+”，在物业行业中属于极高数量级。  
   - 尽管部分案件可能为批量催费或劳动纠纷，但若涉及监控隐私侵权、设备故障导致安全责任等，会直接影响视频巡检数据的完整性和法律合规性。建议后续调研时重点核实其监控系统是否通过公安部门验收、是否有完善的巡检日志留存机制。

5. **公司经营状态与信用评级相对良好，但不代表巡检数据现成可用**  
   - 目前总公司为“存续”，武侯分公司已于2025年12月10日“注销”（企查查更新日期）。  
   - 2024年税务信用评级A级，说明公司纳税规范，经营持续稳定。但视频巡检数据属于内部运营细节，未在公开渠道披露，需进一步向公司内部申请或通过现场走访获取。
