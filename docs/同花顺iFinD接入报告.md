## 四、当前接入架构

```
调度器(300s) → ths_collector.collect_all()
  ├─ THS_RQ → 母公司股票行情 + 概念指数
  ├─ THS_HQ → 60日股价异常检测
  ├─ THS_iwencai → 债券/信用问财搜索
  └─ THS_EDB → PMI/工业增加值/固投
      ↓
  各信号 → Classifier → warning_log → 前端预警中心
```

代码位置：
- `backend/src/services/ths_collector.py` — 同花顺全量采集器
- `backend/src/main.py:581-596` — 调度器集成

## 五、决策建议

试用期结束后：

1. **体验账号就够了？** → 当前 4 个函数对贷后监管核心需求（母公司股价监控、宏观环境判断）基本够用。保留体验账号即可。

2. **升级到正式账号？** → 如果需要：
   - 母公司财务健康分析（营收/利润/负债率趋势）
   - 债券评级自动化采集（替代 DM 查债通的 Playwright）
   - 研报舆情挖掘
   则正式账号能显著减少对其他数据源的依赖（DM、Web Search）。

3. **不续费？** → 同花顺可在采集器中禁用（`WARNING_ENABLED_SOURCES`），企查查+Web Search 仍然可用。
