# 上海票据交易所 API 接入申请流程

> 整理日期：2026-06-23
> 用途：后续票交所数据接入时的操作指南

---

## 一、背景

上海票据交易所（票交所）提供两个接入路径：
- **专线查询接口**（V1.2.0，2021年）—— 已有成熟方案
- **票据综合服务平台直连**（2025年11月上线）—— 新平台，基于互联网

**限制条件**：两个路径均仅对**金融机构**（银行、财务公司）开放。非金融机构无法直接申请，需通过银行方获取凭证。

---

## 二、路径一：专线查询接口（V1.2.0）

### 接入条件

| 条件 | 说明 |
|------|------|
| 机构类型 | 仅限财务公司、银行或其他金融机构 |
| 注册会员 | 必须先成为信披平台注册会员 |
| 测试环境 | 必须先通过测试环境完成接口测试 |
| IP 白名单 | 在平台用户管理模块配置 IP 白名单 |
| 安全凭证 | 系统自动分配 SecretId（企业编号）+ SecretKey（密钥） |

### 申请步骤

1. 填写《金融机构票据信息披露平台信息登记表》
2. 扫描件发送至 `ids@shcpe.com.cn`（2025年3月1日起转为线上申请）
3. 原件快递至票交所（上海市黄浦区半淞园路377号）
4. 注册成功 → 系统自动分配 SecretId + SecretKey
5. 在平台配置 IP 白名单
6. 测试环境联调 → 测试通过 → 切换生产环境

### 核心接口

| 接口代码 | 功能 | 接口地址 | 频率限制 |
|----------|------|----------|----------|
| 0A001 | 单张票查询承兑信息 | `/api/findAcptInfo` | 1次/秒 |
| 0A002 | 批量查询承兑信息（最多500条） | `/api/findBatchAcptInfo` | 1次/10秒 |

### 认证方式

- 签名算法：国密 **SM3**
- 请求参数：`secretId`、`timestamp`、`data`、`signature`
- 签名方法：参数按 ASCII 字典序升序排列，`|` 分隔拼接，SM3 计算签名

### 全局应答码

| 状态码 | 描述 |
|--------|------|
| 9901 | IP 未登记 |
| 9902 | 访问太频繁 |
| 9903 | SecretId 或 SecretKey 验证失败 |
| 9904 | 请求参数值有误 |
| 9907 | 批量查询最多支持 500 条 |
| 9909 | 签名验证失败 |
| 9910 | 无效票据号码 |

## 三、路径二：票据综合服务平台直连（2025年11月上线）

### 平台信息

- 网站：`https://cpisp.shcpe.com.cn`
- 政策依据：票交所发〔2025〕45号
- 定位：互联网端，对专线系统的补充

### 接入步骤

1. 填写《票据综合服务平台上线意向表》（附件4）→ `zfpt@shcpe.com.cn`
2. 参加票交所培训
3. 提交接入验收材料（附件1-3）：
   - 附件1：《数据迁移投产演练及直连接口接入验收申请表》
   - 附件2：《票据综合服务平台宣传展示申请表》
   - 附件3：《票据综合服务平台金融机构信披业务申请表》
4. 报文验收
5. 排期投产上线

### 关键时间线

| 时间 | 事项 |
|------|------|
| 2025年5月28日 | 票交所发布45号文 |
| 2025年6月20日 | 首批意向金融机构截止 |
| 2025年8月 | 开始接入测试 |
| 2025年11月24日 | 综服平台正式投产上线 |
| 2026年 | 非首批机构持续推进接入 |

## 五、对我们项目的意义

### 情况分析

票交所 API 不对非金融机构开放。我们的可行路径：

1. **主路径**：如果银行客户已有票交所接入权限 → 获取其 SecretId/SecretKey → 通过专线接口调用
2. **降级路径**：如果无法获取凭证 → 通过 `cpisp.shcpe.com.cn` 网页手动查询 → 人工录入系统
3. **远期路径**：系统部署到银行内网后 → 可直接复用银行已有的票交所专线

### 接入后可查询的数据

- 商业承兑汇票承兑信息（单张/批量）
- 承兑信用信息（累计承兑额、逾期额、逾期余额）
- 票据逾期记录
- 持续逾期企业名单

### 需要的凭证

- 银行方提供的 **SecretId**（企业编号）
- 银行方提供的 **SecretKey**（密钥）
- 银行方配置的 **IP 白名单**（需将我们的服务器 IP 加入）
