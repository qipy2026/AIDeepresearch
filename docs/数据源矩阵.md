## 四、各数据源详情

### P0-1: 同花顺 iFinD

- **接入方式**：Python SDK (`iFinDPy`)
- **凭证**：`dhsybl002` / `5TSc27g4`
- **关键能力**：
  - `THS_RQ()` — 实时行情（核心企业母公司）
  - `THS_HQ()` — 历史行情 + 异常检测
  - `THS_EDB()` — 宏观经济 EDB 数据库
  - `THS_iwencai()` — 问财搜索（含舆情资讯链接）
- **限制**：仅覆盖上市公司和宏观指标，未上市债务企业无法查询
- **代码位置**：`backend/src/services/ths_client.py`（当前为 HTTP API 模式，需切换到 Python SDK）

### P0-2: 企查查 MCP

- **接入方式**：SSE 流式 JSON-RPC
- **凭证**：已有 Token
- **关键能力**：
  - `company_profile()` — 企业概况
  - `risk_scan()` — 风险扫描概览
  - `administrative_penalty()` — 行政处罚
  - `judicial_documents()` — 裁判文书
  - `dishonest_info()` — 失信被执行
  - `bidding_info()` — 招投标
  - `news_sentiment()` — 新闻舆情
  - `key_personnel()` — 高管信息
  - `recruitment_info()` — 招聘动态
  - `qualifications()` — 资质证书
- **限制**：返回自然语言文本，非结构化计数
- **代码位置**：`backend/src/services/qichacha_mcp.py`

### P0-3: DM 查债通

- **接入方式**：Playwright 浏览器自动化
- **凭证**：`luoxiaojuan` / `thlz2025`
- **关键能力**：
  - 债券违约标志
  - 结构化司法计数（被执行人/失信/限高/法院公告/立案/开庭/裁判文书）
  - 负面舆情标题
  - 企业基本信息（信用代码/法人/注册资本/实缴资本）
- **限制**：Playwright 启动开销，每次采集需 ~5-10 秒
- **代码位置**：待保存到 `backend/src/services/dm_client.py`

### P1-1: Web Search

- **接入方式**：HTTP 搜索 API（DuckDuckGo/Tavily）
- **凭证**：无
- **关键能力**：
  - 问政四川 / 麻辣社区投诉平台
  - 招标网 / 中标公告
  - 东方财富 / 搜狐新闻
- **限制**：海外搜索引擎，国内源覆盖不完整
- **代码位置**：`backend/src/services/web_search.py`

### P1-2: 抖音标题搜索

- **接入方式**：Playwright 浏览器自动化
- **凭证**：账号待补充
- **关键能力**：搜索企业名 → 提取视频标题 → 关键词预筛
- **限制**：需要登录账号；中小企业在抖音内容少
- **代码位置**：待开发 `backend/src/services/douyin_collector.py`
- **验证结果**：
  - ✅ Playwright stealth 模式可绕过反爬检测
  - ❌ 搜索结果在登录墙后，需要账号 Cookie

### P1-3: 票交所

- **接入方式**：RAG 手动流程
- **凭证**：`鼎辉` / 密码待输入
- **流程**：登录 `cpisp.shcpe.com.cn` → 搜索企业 → 保存网页 → 上传系统 → ChromaDB 索引 → 预警查询时检索
- **参考文档**：[票交所API接入申请流程.md](票交所API接入申请流程.md)

## 五、同花顺 Python SDK 实测记录

| 功能 | 代码 | 结果 |
|------|------|:--:|
| 登录 | `THS_iFinDLogin('dhsybl002', '5TSc27g4')` | ✅ |
| 实时行情 | `THS_RQ('601186.SH', ...)` | ✅ 中国铁建 6.36, PE/PB/市值 |
| 历史行情 | `THS_HQ('601186.SH', ...)` | ✅ 33 条交易记录 |
| GDP 宏观 | `THS_EDB('M001620326', ...)` | ✅ 2026Q1: 334,192.9 亿 |
| 概念指数 | `THS_HQ('885692.TI', ...)` | ✅ 地下管网 1299 点 |
| 问财搜索 | `THS_iwencai('四川振海', 'bond')` | ⚠️ 返回"四川概念指数"非公司债券 |
| 中国铁建债券 | `THS_iwencai('中国铁建', 'bond')` | ❌ 无双债券记录 |
| 基本面指标 | `THS_BasicData(...)` | ❌ 参数格式待调整 |

**结论**：同花顺对上市公司母公司（中国铁建 601186.SH）价值显著；对未上市债务企业（四川振海）仅提供行业概念层面数据。
