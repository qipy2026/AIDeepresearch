## 修改清单（4 个文件）

### 文件 1：`generator.py` — 替换 3 处硬编码

**改动 A**：`_build_section_data()` 中 industry_data 调 `_fetch_industry_data()`：

```python
def _fetch_industry_data(self, industry: str) -> dict:
    from services.web_search import dispatch_search
    results = dispatch_search(f"{industry} 行业 最新动态")
    events = [r["title"] for r in results if "政策" not in r["title"]]
    policies = [r["title"] for r in results if "政策" in r["title"]]
    negative_kw = ["风险","下降","萎缩","违约","处罚","下滑","亏损"]
    hits = sum(1 for r in results if any(kw in r.get("title","") for kw in negative_kw))
    risk_warning = f"监测到{hits}条负面信号。" if hits else "未发现明显负面信号。"
    return {
        "situation": "行业分析待生成。",
        "status": "正常",
        "key_indicators": f"搜索到 {len(results)} 条相关资讯",
        "major_events": events[:5],
        "policy_direction": "中性",
        "policy_detail": policies[0] if policies else "暂无最新政策信息。",
        "risk_warning": risk_warning,
    }
```

**改动 B**：supply_chain 改查 AlertEvent 表（`_fetch_core_enterprise_data()`），按企业+周期过滤，按 alert_type 分组填充字段
